# EPFL Spacecraft Team website

Source of [epflspacecraftteam.ch](https://www.epflspacecraftteam.ch), hosted on GitHub Pages.
Plain HTML + CSS, no build step: what you see in this repo is what goes online.

## Structure

```
index.html            Home page
<page>/index.html     One folder per page (keeps URLs like /team, /contact)
css/                  Shared styles
content/              Job offers, semester projects, department descriptions (updated each semester)
logos/                Team / mission logos
sponsors/             Sponsor logos
portraits/            Team member photos
```

## Rules for contributors

- **File names:** lowercase, no spaces, no accents. `jean-dupont.webp`, not `Jean Dupont.JPG`. Links are case-sensitive.
- **Images:** portraits ~800 px wide (WebP or JPG), logos as SVG when possible. Keep files under 500 KB.
- **Uploading:** on GitHub, *Add file > Upload files* and drag files or folders in (max 100 files per upload), then *Commit changes*. For regular edits, [GitHub Desktop](https://desktop.github.com) is easiest.
- Changes go live a minute or two after each commit.
